# Meu Eletricista - Site Moderno

Site responsivo para empresa de elétrica, criado com HTML5, CSS3 e Bootstrap 5.

## 🏠 Sobre o Projeto

O site foi desenvolvido para a empresa de elétrica **"Meu Eletricista"**, localizada em Juiz de Fora e região. O projeto se destina a serviços em áreas:
- 🏠 **Residencial**
- 💼 **Comercial**
- 🏭 **Industrial**
- 🏢 **Condomínios**

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização avançada
- **Bootstrap 5** - Framework responsivo
- **Bootstrap Icons** - Ícones personalizados
- **Google Fonts** - Fonte Poppins

## 🔧 Como Utilizar

### Opção 1: Abrir Diretamente

1. Navegue até a pasta `Site Boots`
2. Abra o arquivo `index.html` no navegador

### Opção 2: Utilizar Servidor Local

```bash
# Navegue até a pasta do projeto
cd "C:\omnirote-claude\Site Boots"

# Inicie um servidor HTTP simples
python -m http.server 8000

# Ou use Node.js
npx http-server
```

Em seguida, acesse: `http://localhost:8000`

### Opção 3: Deploy em Hosting Gratuito

- **Netlify**: Arraste a pasta e faça upload
- **Vercel**: Conecte seu GitHub e deploy
- **GitHub Pages**: Configure como branch principal

## 🎨 Personalização

### Alterar Cores

Edite as variáveis CSS em `style.css`:

```css
:root {
    --accent-color: #ffc107;  /* Cor de destaque (amarelo) */
}
```

### Alterar Textos

Edite o conteúdo em `index.html`:
- Dados da empresa
- Informações de contato
- Seções do site

### Integrar Backend

O formulário está estruturado. Para processar os dados:
1. Substitua `action=""` na tag `<form>`
2. Adicione JavaScript para capturar e enviar dados
3. Use serviços como Formspree ou EmailJS
